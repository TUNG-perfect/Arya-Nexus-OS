🚀 ARYA NEXUS OS

A modern, browser-based operating system simulator built with HTML, CSS, and JavaScript.

ARYA NEXUS OS is a desktop-style operating system simulation designed to bring the look and feel of a modern computer environment into your browser.

It features a desktop interface, draggable application windows, a file manager, a terminal, a calculator, and a built-in browser experience.

This project is a simulation, not a standalone operating system or a replacement for macOS, Windows, or Linux.

⸻

✨ Features

* 🖥️ Desktop Environment — A modern desktop interface.
* 🪟 Window Management — Open, move, and manage application windows.
* 📁 File Manager — Explore a simulated file system.
* 🌐 Web Browser — Browse websites and search the web.
* 💻 Terminal — Use built-in simulated terminal commands.
* 🧮 Calculator — Perform basic mathematical calculations.
* ⚙️ Settings — Customize the desktop experience.
* 📊 Task Manager — View running simulated applications.
* 🔄 Boot Animation — Experience an operating-system-style startup.

🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Local Storage

🚀 Getting Started

Option 1: Run in a Browser

1. Download or clone this repository.
2. Locate ARYA_NEXUS_OS_2.1_FULL_CODE.html.
3. Open the file in your browser.
4. Enjoy ARYA NEXUS OS!

Option 2: Run Locally with VS Code

1. Open the project folder in Visual Studio Code.
2. Open the HTML file.
3. Run it using Live Server or your preferred local web server.

📌 Important Notes

* ARYA NEXUS OS is currently a browser-based simulation.
* The terminal uses simulated commands and does not execute real macOS or Linux shell commands.
* The file manager uses browser storage rather than accessing your computer’s actual file system.
* Website availability depends on your browser and network connection.
